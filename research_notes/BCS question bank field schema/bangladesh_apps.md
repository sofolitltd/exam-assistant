# Bangladeshi BCS / Govt-Job MCQ Prep Products: Question Metadata, Filters, Modes, Analytics

Research date: 2026-11-20. Method: Google Play listing descriptions (fetched directly; download counts and "Updated on" dates read from the listing HTML), Live MCQ product web page, Satt Academy job-solution pages, publisher/bookshop pages for guide books, and news reports on the BPSC syllabus. "Observed" means stated on the product's own page/listing. Play descriptions are vendor self-claims, not verified in-app behaviour. Several Play listings 404'd or gave blank pages through the fetch tool, so they were read via raw HTML.

## 1. Which products exist and how popular are they?

### Takeaway
Live MCQ (1M+ installs, 2.4M+ claimed users) is clearly the market leader for BCS/job MCQ prep; next tier is BCS Prostuti (500K+), GuruKlub, Medha, Biddabari, "Bcs Question Bank and Solution" (each 100K+) and Job Solution Book BD (100K+). Satt Academy is the largest web question archive (claims 20 lakh+ explained Q&As). Printed "digests" (Professor's, Preceptors, Assurance) remain the reference format for topic-wise previous-question solutions.

## 2. How do they classify questions (metadata)?

### Takeaway
The near-universal metadata is: exam source (exam body + exam number/name, e.g. "৪৬তম বিসিএস প্রিলিমিনারি", date/year, set name for multi-set papers), subject (the 10 BPSC preliminary subjects), chapter/topic (often category → subcategory → chapter), answer, explanation (ব্যাখ্যা), and increasingly a reference/source and answer-dispute/correction notes. Difficulty is rarely shown explicitly; "important"/repeat markers appear in analytics ("which chapter gets most questions") rather than as per-question fields in the listings found.

### Cited Findings
**Exam source / paper identity**
- Satt Academy lists each BCS paper with exam number, type, date and MCQ count, e.g. "50th BCS Preliminary Test — 2026-01-30 — MCQ 200"; "47th BCS Preliminary Test (Chandramallika set, English version)"; "45th (unselected set, Kirtankhola 2023)"; special BCS papers like "48th Special (Dental Science)", "49th Special (Education), Department — MCQ 1100", "42nd Special (Health Cadre) — 100"; older preliminaries 27th–34th show 100 MCQs, 35th onward 200. 47 BCS entries total. — [Satt Academy BCS Preliminary](https://www.sattacademy.com/job-solution/bcs-preliminary/)
- ⇒ Paper metadata needed: exam_number, exam_kind (regular / special + cadre), set name (named sets like "চন্দ্রমল্লিকা", "কীর্তনখোলা"), version/medium (Bangla/English version), exam date, total MCQs.

### Inferences
- Topic-wise arrangement in digests implies each question is tagged with both source exam(s) and syllabus topic; the common print convention (from domain knowledge, not verified here) is a bracketed source tag after each question, e.g. "[৪৪তম বিসিএস]", listing multiple exams when repeated — this is how "repeated" status is conveyed. Treat as unverified.
- Schema implications: a question can belong to many sources (same question appeared in several exams) → many-to-many `question_sources` (exam_id, set, question_no). Need `answer_status` (official / disputed / corrected), `correction_note`, `corrected_at`, `reference` (book + page/URL), `info_updated_note` (outdated facts), `language/version`, `is_cancelled`/excluded.
- Difficulty is not a standard user-facing field in this market (only Medha mentions it); likely computed from user accuracy rather than editor-assigned.

### Gaps
- Could not observe an actual in-app question card (screenshots not accessible), so exact per-question labels like "একাধিকবার এসেছে", star/important markers, or "BPSC-এর উত্তর ভুল" could not be confirmed from primary sources.
- No access to guide-book sample pages; "বিগত প্রশ্ন বিশ্লেষণ" table format of Professor's/MP3/Oracle not verified.

## 3. What user-facing filters, practice modes and analytics exist?

### Takeaway
Standard feature set: paper-by-paper previous questions; subject/chapter practice; custom tests (choose category/subcategory/chapter, question count, time); timed full model tests (200 Q, 0.5 negative marking, subject-wise result); daily/weekly live exams with merit lists; wrong/unanswered lists ("Mistake Vault"); bookmarks/mark-for-review + personal notes; smart/fuzzy search; subject-wise performance and weak-area detection; trend analysis of which chapters get most questions; gamified quizzes/battles; spaced repetition in newer apps.

## 4. How do guide books structure BCS preliminary question analysis?

### Takeaway
Publisher pages confirm that the major digests (Professor's, Preceptors, Assurance) arrange 10th–50th BCS preliminary questions topic/chapter-wise with explanations, built on "বিগত বছরের প্রশ্ন পর্যালোচনা ও বিশ্লেষণ", and updated to the current BPSC syllabus; detailed analysis-table formats could not be verified online.

### Cited Findings
- Professor's 47th edition: solutions of 35th–46th BCS preliminary questions "BCS সিলেবাস অনুসরণ এবং বিগত বছরের প্রশ্ন পর্যালোচনা ও বিশ্লেষণে রচিত"; 49th-special edition arranged chapter-wise by previous-year questions. — [eboighar: Professor's Digest](https://www.eboighar.com/booksdetails/72064/), [eboighar 73772](https://eboighar.com/en/booksdetails/73772)
- Preceptors: all 10th–50th BCS preliminary questions presented "টপিকভিত্তিকভাবে ব্যাখ্যাসহ"; important info added for latest BPSC syllabus. — [Preceptors](https://preceptors.com.bd/product/bcs-digest/)
- A govt teachers' portal guideline lists previous-question analysis, regular model tests and mistake analysis as the core of preliminary prep. — [teachers.gov.bd 51st BCS guide](https://www.teachers.gov.bd/blog/details/842557)
- Live MCQ publishes per-exam solution PDFs (e.g. 35th, 37th, 38th, 43rd BCS). — [Live MCQ 37th BCS solution](https://web.livemcq.com/37th-bcs-question-solution-pdf/)

### Inferences
- Digest = question rows tagged (topic, source exams) + explanation; an app question bank reproducing this needs topic as primary navigation and source exam(s) as tags — matching the many-to-many source model above.

### Gaps
- No online evidence found for MP3 or Oracle BCS preliminary guide structures, nor for the exact layout of topic-wise "বিগত প্রশ্ন বিশ্লেষণ" tables (counts per topic per BCS). Would require physical copies or sample-page images.
